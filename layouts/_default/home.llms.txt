# {{ site.Title }}

> {{ .Description | plainify | chomp }}

Weasis is a free, open-source DICOM viewer for medical imaging. It runs as a
standalone desktop application on Windows, macOS and Linux, and can also be
launched from a web portal or PACS front end through the `weasis://` URI scheme.
This file maps the documentation published at {{ site.Home.Permalink }} so it can
be read without parsing HTML; {{ "llms-full.txt" | absURL }}
contains the full text of every page below.

Things worth knowing before quoting this documentation:

- Source code: https://github.com/nroduit/Weasis — dual licensed EPL-2.0 OR Apache-2.0.
  The documentation itself is CC BY-SA 4.0: https://github.com/nroduit/nroduit.github.io
- The open-source distribution of Weasis is **not** a certified medical device:
  no CE marking, no FDA clearance. Primary diagnostic use is the responsibility
  of the user or institution. See the FAQ entry on certification.
{{ if $current }}- This site documents Weasis {{ $oldest }} to {{ $newest }}; {{ $current }} is the current release.
  Differences between releases are marked inline in the prose as "since vX.Y" or
  "up to vX.Y", and one page per topic covers every documented version — there is
  no per-version copy of a page, and no per-version URL other than the optional
  `?v=X.Y` hint on a link.
{{ end }}- Questions and support: https://github.com/nroduit/Weasis/discussions
