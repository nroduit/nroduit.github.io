{{- /*
  /llms-full.txt — the whole documentation as one plain-text file, the companion
  to the /llms.txt index (https://llmstxt.org/).

  The source Markdown is emitted rather than the rendered HTML: headings, tables
  and links survive, while the sidebar, the version selector, the galleries and
  the analytics markup do not. Shortcodes are unwrapped instead of dropped — the
  `since` and `until` badges become the plain words a model can act on, and block
  shortcodes such as `notice` keep their inner prose. Inline
  <style> and <script> blocks (the home page has both) are removed outright.

  Inline HTML written inside a page (the home page's card grid, for instance) is
  kept as it stands: a model reads it without trouble, and guessing which tags
  are layout and which carry meaning would do more harm than good.

  This is a derived artifact: nothing here is authored, so a page that reads
  badly in this file reads badly in its Markdown too.
*/ -}}
