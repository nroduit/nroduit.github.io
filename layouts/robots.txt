# This documentation exists to be read, quoted and indexed — by search engines
# and by AI assistants alike, since "which free DICOM viewer opens a DICOM CD?"
# is now as likely to be asked of an assistant as of a search box. Everything is
# therefore open to every crawler, including the ones that train models; the
# content is CC BY-SA 4.0 and attribution in an answer is how people find Weasis.
#
# Two plain-text renderings are published for language models, following the
# convention at https://llmstxt.org/ :
#
#   {{ absURL "llms.txt" }}       annotated map of every page
#   {{ absURL "llms-full.txt" }}  the whole documentation in one file
#
# Only three kinds of URL are withheld, none of which is content: the JavaScript
# search page, which renders nothing without a query, and the tag and category
# listings, which no page on this site populates. The taxonomy paths are spelled
# out one language at a time rather than as /*/tags/, which would also match the
# DICOM attributes tutorial at /en/tutorials/tags/. They carry the base URL's own
# path prefix, which is empty on this domain but not in a build served from a
# subdirectory — a robots path is absolute on its host, so the prefix belongs in
# it. The printer-friendly rendering of each page (…/index.print.html) is left
# crawlable on purpose even though it is served `noindex`: a crawler has to fetch
# a page to be told not to index it, and blocking it here would leave the
# duplicate address eligible for the index on the strength of its inbound links.

# grants access that was missing. The point of naming these is that this file is
# also read by people — and by the vendors' own opt-out tooling — deciding whether
