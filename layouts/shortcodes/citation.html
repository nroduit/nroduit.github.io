{{- /* Citation entries for a release the reader picks, on /en/cite/. The release list is fetched at build time from the GitHub releases API — the same source as `latest-download` and `/api/release/api.json` — so the versions and their dates are the real ones and nothing has to be maintained by hand in the page. Each entry is emitted as HTML with the latest release already filled in and the variable parts wrapped in , so with JavaScript off the page shows a correct citation for the current release; the selector only rewrites those spans. The entries are hand-built HTML rather than Markdown fences because a fenced block escapes the spans, which is what the variable parts need. Degradation, in order: - `HUGO_GH_TOKEN` set : authenticated request, no rate limit worries in CI - no token : unauthenticated request, which works for a public repository and keeps local builds honest - request fails : the `current` entry of data/versions.toml, with a build warning. The page still renders a citation; it just offers one version instead of a list. Params: repo GitHub repository, default nroduit/Weasis limit how many releases to offer, default 25 (older ones stay on GitHub) */ -}} {{- $repo := .Get "repo" | default "nroduit/Weasis" -}} {{- $limit := int (.Get "limit" | default 25) -}} {{- $token := getenv "HUGO_GH_TOKEN" -}} {{- $opts := dict -}} {{- with $token }}{{ $opts = dict "headers" (dict "Authorization" (printf "Bearer %s" .)) }}{{ end -}} {{- $url := printf "https://api.github.com/repos/%s/releases?per_page=100" $repo -}} {{- $releases := slice -}} {{- /* `try` is how a failed remote fetch is caught since Hugo 0.141: a network error or a rate-limited API must not break the build of a page whose point is to be citable. */ -}} {{- with try (resources.GetRemote $url $opts) -}} {{- with .Err -}} {{- warnf "citation: cannot read %s (%s) — falling back to data/versions.toml" $url . -}} {{- else with .Value -}} {{- range . | transform.Unmarshal -}} {{- if and (not .prerelease) (not .draft) .tag_name -}} {{- $when := time (or .published_at .created_at) -}} {{- $releases = $releases | append (dict "version" (strings.TrimPrefix "v" .tag_name) "date" ($when.Format "2006-01-02") "long" ($when.Format "2 January 2006") "year" ($when.Format "2006")) -}} {{- end -}} {{- end -}} {{- else -}} {{- warnf "citation: empty response from %s — falling back to data/versions.toml" $url -}} {{- end -}} {{- end -}} {{- if not $releases -}} {{- $current := "" -}} {{- range where (partialCached "_weasis/versions.gotmpl" site.Home) "isLine" false -}} {{- if eq .state "current" }}{{ $current = .id }}{{ end -}} {{- end -}} {{- $releases = slice (dict "version" ($current | default "4.7") "date" (now.Format "2006-01-02") "long" (now.Format "2 January 2006") "year" (now.Format "2006")) -}} {{- end -}} {{- $releases = first $limit $releases -}} {{- $latest := index $releases 0 -}} {{- $today := now.Format "2 January 2006" -}}
Showing {{ $latest.version }}, released {{ $latest.long }}.
